
# OrangeHRM Manual Testing Project

## Project Overview

This project focuses on manual testing of the OrangeHRM web application.

The objective is to practice functional testing, test case design, defect reporting, and test documentation using a real-world HR management application.

## Modules Under Test

- Login
- Dashboard
- Employee Management
- Add Employee
- Search Employee
- Leave Management
- Logout

## Test Artifacts

- Test Plan
- Test Cases
- Bug Reports
- Test Summary Report

## Tools Used

- OrangeHRM
- Google Chrome
- GitHub
- Markdown
