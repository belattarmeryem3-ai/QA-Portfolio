# Test Plan

## 1. Introduction

This test plan describes the testing approach for the OrangeHRM web application.

The purpose of this project is to verify that the main features of the application work as expected and to identify defects through manual testing.

## 2. Test Objectives

The main objectives are:

- Verify that users can log in successfully.
- Verify employee management functions.
- Verify employee search functionality.
- Verify leave management functions.
- Verify form validations and error messages.
- Verify that users can log out successfully.

## 3. Scope

### In Scope

- Login
- Dashboard
- Employee Management
- Add Employee
- Search Employee
- Leave Management
- Logout

### Out of Scope

- Performance testing
- Security testing
- API testing
- Database testing
- Mobile application testing

## 4. Test Types

- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing
- Validation Testing
- Regression Testing

## 5. Test Environment

| Item | Details |
|------|---------|
| Operating System | Windows 11 |
| Browser | Google Chrome |
| Testing Type | Manual Testing |

## 6. Entry Criteria

Testing will begin when:

- The application is accessible.
- The required test environment is available.
- The main application features are functional.

## 7. Exit Criteria

Testing will be considered complete when:

- All planned test cases have been executed.
- All identified defects have been documented.
- Test results have been reviewed.
- The Test Summary Report has been completed.

## 8. Deliverables

The following documents will be produced:

- Test Plan
- Test Cases
- Bug Reports
- Test Summary Report

## 9. Risks

Potential testing risks include:

- Application downtime.
- Unexpected application behavior.
- Environment or browser issues.
- Limited testing time.

## 10. Conclusion

This test plan provides the overall approach for testing the main functionalities of the OrangeHRM application through manual testing.
