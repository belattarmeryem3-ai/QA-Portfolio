# Test Plan

## 1. Project Information

**Project Name:** SauceDemo Web Application

**Application Under Test:** https://www.saucedemo.com/

**Prepared By:** Meriam

**Document Version:** 1.0

**Date:** August 2026

## 2. Objective

The objective of this test plan is to verify that the core functionality of the SauceDemo web application works as expected.

The testing will focus on validating the login process, product browsing, shopping cart, and checkout functionality to ensure a smooth user experience.

## 3. Scope

### In Scope

The following features are included in testing:

- User Login
- Product Listing
- Shopping Cart
- Checkout Process
- Logout

### Out of Scope

The following items are not included in this testing:

- Performance Testing
- Security Testing
- Mobile Application Testing
- Compatibility Testing on multiple browsers
